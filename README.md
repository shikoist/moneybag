Hello everyone.
I wrote this script for game/fun/nostalgia evening with friends for Vice City Multiplayer. If you'll like it, cool.
Required plugins: squirrel04 xmlconf04

Features:
8 businesses (got cash every 6 minutes, map marker appears, when it has cash, and disappears, when cash is gone)
3 ammo shops (weapons and costs from original Vice City)
players drops money and weapons (creates pickups, like original game)
player starts with nothing
